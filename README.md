# KodeKloud's 100 Days of DevOps

This repository contains my solutions to the tasks in KodeKloud's 100 Days of DevOps course.  Each day has its own directory, and each directory contains a `readme.md` file with the task description, my solution, validation steps, and my personal insights on the tasks.

I will be updating the repository as I complete the solutions.  Sometimes I'll do a single task a day, sometimes I'll do multiple tasks in a day, and sometimes I'll take a break for a few days, but I'll try to keep it as consistent as possible.

I hope this repository will be useful for anyone who is taking the course or is interested in learning DevOps in general, or wants to see how I approach these tasks.  

Please feel free to fork the repository and share your solutions as well.
